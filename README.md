# CV interactif · Anthony Catan-Cavery

Mon CV sous forme de page web, pour ma recherche de stage de 2 mois
(titre Concepteur Développeur d'Applications, spécialité Java, ENI).

**Voir la page : https://anthonycc-g.github.io/CV-interactif/**

Un CV classique d'une page est aussi disponible dans la page, via le bouton « Télécharger en PDF ».

## Ce que contient la page

- Mon parcours : compétences, projets, expériences, formations
- Un mode clair et un mode sombre
- Une interface pensée pour l'accessibilité : navigation au clavier,
  lecteurs d'écran, respect de la préférence « mouvement réduit »

## Technique

HTML, CSS et JavaScript, sans framework ni dépendance.
La page s'ouvre en local en double-cliquant sur `index.html`.
